# Re:Emerald Changelog

## In-development
**Update 13**
- Added the Medicine and Battle Items pockets to the bag
- Added a Potion to the bag when starting a new game, to replace the one that used to be in the PC storage

**Update 12**
- Made the Old Sea Map obtainable
- Removed the "can only be taught once" warning from all Move Tutors
- Fixed a bug that made Contests not give Luxury Balls when winning if the Pokemon didn't have the corresponding Ribbon

**Update 10-11**
- Berry plants no longer disappear or start growing again after raching the fully grown stage
- The formula for calculating the extra berry yields was changed and is no longer random
- The minimum and maximum yield for all berries were changed
- Changed some dialogues from berry NPCs to be more in line with the new behavior

**Update 9**
- Expanded the bag to hold 1 of every item at the same time
- Changed Exp. Share to work like in Gen VI

**Update 8**
- Changed the line of sight of the Gentleman in Route 121. Now you can reach the item without fighting him or without going through the grass
- Shortened the messages when picking up a berry
- When asked to change Pokemon, you can still see what Pokemon the opponent will send out
- Fixed the capitalization and name of some items and descriptions

**Update 7**
- Added a list to the Pokemon's menu that shows any field moves it can use that can be used from the overworld
    - This fixes the issue that made Regirock unobtainable due to being locked behind Rock Smash

**Updates 2-6**
- Implemented the Swarm mechanic:
    - Swarm Pokemon show up in the Pokedex correctly
    - Implemented Birch's book for active swarms
- Increased the variety of wild Pokemon in some areas

**Update 1**
- Modified the in-game trades to be more useful

## 0.1.0
- Initial game release
